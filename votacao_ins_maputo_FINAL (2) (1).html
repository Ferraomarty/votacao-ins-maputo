Configuração da base de dados — 5 passos rápidos (apenas uma vez)

1Vai a console.firebase.google.com e clica em Criar projecto (conta Google gratuita)
2No menu lateral clica em Build → Realtime Database → Criar base de dados → escolhe Iniciar em modo de teste
3Copia o URL que aparece no topo: https://SEU-PROJECTO-rtdb.firebaseio.com
4Abre este ficheiro HTML num editor de texto (Notepad) e substitui COLE_AQUI_O_URL_DO_FIREBASE pelo URL copiado
5Arrasta o ficheiro para netlify.com/drop → partilha o link com a equipa!
